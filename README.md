# 我有做事

記錄每天做了什麼的生活日誌，概念像記帳。

🔗 線上體驗：https://i-do-something.vercel.app/

## 功能
- 月曆檢視，點日期就能新增當天做的事
- 自訂項目與分類（家事、出去玩、工作、健康）
- 成就解鎖與生活證書
- 匯出 CSV / JSON 備份

## 技術
JavaScript、HTML/CSS，部署在 Vercel。

## 資料說明
資料目前儲存在瀏覽器本機（localStorage），不會上傳到伺服器。
之後若要做雲端同步，可以用匯出的 CSV / JSON 轉移資料。
